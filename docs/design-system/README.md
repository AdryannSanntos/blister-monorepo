# Workana AI Design System

## Objetivo

Consolidar a base visual oficial do Workana AI: uma interface B2B operacional, premium, clara e autoral para empresas que coordenam freelancers, fornecedores e times remotos.

## Direção

- Light theme como padrão.
- Dark theme disponível, com paridade real.
- Fundo off-white frio puxado para azul.
- Azul como acento principal.
- Dourado apenas para premium.
- Lime discreto para estados de IA ativa.
- Nada de preto absoluto ou branco puro como linguagem principal.
- Interface profissional, tecnológica, elegante e levemente editorial.
