# Foundations — Workana AI

## Personalidade

Workana AI deve parecer uma ferramenta séria para empresas coordenarem trabalho externo com mais contexto, controle e velocidade. A interface é premium, operacional e inteligente, sem parecer um chatbot genérico.

## Princípios

- Clareza antes de decoração.
- Densidade controlada para operação B2B.
- IA visível, mas não espalhafatosa.
- Conteúdo e contexto sempre auditáveis.
- Permissão e governança como parte da UX.

## Tema

Light theme é o padrão. Dark theme existe para preferência do usuário, mas não define a identidade primária.

## Layout

- Dashboard com sidebar fixa/collapsible.
- Header sticky com contexto do workspace.
- Páginas com uma ação principal clara.
- Tabelas para dados operacionais.
- Cards para resumo, onboarding, navegação e estados especiais.
