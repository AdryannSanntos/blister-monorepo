# Minimal Clean — Template Instructions

## Identity
- Colors: Background #0a0a0a (dark slides) or #f9f9f7 (light slides)
- Typography: System-ui, bold weights (700-900)
- Spacing: 64-72px padding

## Slide types
- start: Dark background, large bold title centered
- text: Numbered habit layout, light or dark variants
- text_image: Image occupying 55% top or 40% side, text below/beside
- image: Full bleed image with text overlay

## Variables
Use: {{title}}, {{body}}, {{call_to_action}}, {{image_url}}
